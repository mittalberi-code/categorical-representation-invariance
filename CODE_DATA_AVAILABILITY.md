# Code and data availability

## Archival identity and scope

This release archive accompanies Zenodo record https://zenodo.org/records/24110689, DOI https://doi.org/10.5281/zenodo.24110689, version 0.3, prepared for the author-review manuscript v0.5. It contains original study code, constructed synthetic inputs and computational outputs, together with preserved source provenance, environment records and reproducibility instructions. The synthetic study inputs do not contain human-participant records.

On the published open-access record, the archive can be downloaded without an account. The repository record is authoritative for publication and access status.

Original code is GPL-3.0-only; original synthetic data, results and documentation are CC BY 4.0. Preserved riskutility 0.2.0 material, including copied and printed upstream functions, retains its existing GPL-3 terms. The exact scope is in `LICENSES.md` and `THIRD_PARTY_NOTICES.md`.

## Preservation and curation

Zenodo's published policy states that deposited items are retained for the lifetime of the repository. Data and metadata are replicated and backed up; stored files are checked against their checksums. Zenodo does not guarantee continued usability or understandability of deposited objects. Its succession policy is to make best efforts to transfer content if the repository closes. Policy checked 10 November 2026: https://about.zenodo.org/policies/.
