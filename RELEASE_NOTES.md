## Verified evidence and remaining limits

Python experiments were rerun twice during packaging and matched retained results byte-for-byte. The retained native tables were checked against exact tuple references. The root verification script also checks the complete payload manifest. See the included reports for counts and methods.

A fresh native R reproduction in an independently provisioned environment has not been performed. The portable native wrapper/export path has not been executed end to end in this packaging environment, where R is unavailable. Two original clean R processes in one environment establish repeatability, not independent-environment replication. Observed dependencies are an inventory rather than a fully tested clean-install lock.

The archive does not settle publication-level novelty, current upstream behavior, real-world identification success, institutional ethics determinations, journal suitability or the author's final submission declarations. These are not prerequisites silently marked complete by archiving the bounded evidence.
