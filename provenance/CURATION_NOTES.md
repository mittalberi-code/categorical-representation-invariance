# Curation record

Source artifacts: v0.5 manuscript/supplement/LaTeX source, Privacy_Native_R_Inputs.zip, Privacy_Native_R_Results_20261110.zip, and retained Python unit-07 evidence. Their source hashes are recorded in INPUT_HASHES.json.

Preserved byte-for-byte: original Python study, prepared CSVs, expected.csv, original Python result objects, native CSV/raw outputs, selected session records, riskutility archive and extracted upstream files. In v0.2, two unnecessary introductory preparation/process comment lines were removed from each author-written R runner. All non-comment lines and essential scientific/provenance comments remain unchanged. Historical execution is proven separately by retained raw outputs and receipts.

Derived: Python input JSONL is losslessly exported from retained result rows. Native package-version CSV extracts only Package/Version from the historical installed-package listing. Native summary omits the ephemeral machine path and renames historical `unique_fixture_count` to `named_fixture_count`, adding the independently calculated 54 byte-distinct count. Installed-source comparison is transcribed into a path-free curated JSON receipt; its unmodified source remains in the original private native bundle.

New: documentation, metadata, offline checker, Python reproduction wrapper, native shell wrapper. Native export script changes only root-path input from a hard-coded machine directory to a command-line argument. The upstream package is unchanged.

Excluded: duplicated original nested input ZIPs, system install/download receipts, legacy orchestration scripts tied to machine paths, install command/environment metadata containing temporary directories, cache/bytecode, session/account/browser data and manuscript/style files.

Privacy inspection is a bounded artifact review, not a mathematical guarantee that all possible secrets can be recognized. Study records are inspected constructed strings. Public upstream author/contact metadata is retained inside the third-party source for attribution, not presented as participant data.

Release v0.3 updates documentation and metadata only. The study code, constructed inputs, retained outputs and upstream files remain byte-identical to private preparation v0.2. Historical QA reports remain identified as historical evidence.
